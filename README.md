# 《空出来的座位》作品说明

融合新闻 · 交互式数据报道 · 单文件网页

---

## 一、选题与立意

**报道对象不是"2025 年新生儿数量"，而是近三十年出生人口的宏观趋势，以及它与结婚、教育、就业三条线的关系。**

标题不用数字，因为数字会把报道窄化成一次年度统计。**"空出来的座位"**指向的是这些数字最终落地的位置：产房的床位、幼儿园的小椅子、小学的课桌、考场、大学的招生计划、招聘会的展位。座位是按人准备的，人少了，座位就空出来。

**对应「四个面向」：** 面向经济主战场、面向国家重大需求。人口是教育、就业、住房、养老所有系统的分母。

**时间跨度：** 1996–2025 年，三十年。中途的 2016 年（全面二孩）与 2024 年（疫情补偿 + 龙年）两次反弹，都只维持一年。

## 二、结构

杂志式长页，**全部单列**，图表全宽（1000–1100px），段间用全宽图片与浅色区块分隔，页面拉到约 20000px。

```
封面　　　全屏大图 + 标题，无 logo、无年份、无机构名，纯粹留白
引言　　　首字下沉，交代三条线的关系
全宽图①　空荡的幼儿园
壹 · 三十年　　整幅出生曲线（520px 高）→ 三个大数字 → 两次反弹柱图
贰 · 四间教室　1970s / 2020 / 2023 / 2024 四组「图 + 人口数 + 说明」左右交替
　　　　　　　　　最后接一张四行对比表
引述　　　整幅浅色区块，何亚福「昙花一现」
叁 · 三条线　　指数化剪刀差图（520px）→ 结婚登记柱图
　　　　　　　　→ 叠卡组图「三条线·三张面孔」→ 档案卡（1270 vs 792）
全宽图②　高三教室
肆 · 为什么　　三个原因编号卡（分母 / 结婚 / 生育率）→ 名词卡
　　　　　　　　→ 叠卡组图「三个变量·三张照片」→ 时间轴七个节点
伍 · 影响　　　传导时钟表 → 叠卡组图「缺口往上推」
　　　　　　　　→ 老人与孩子对比 → 三个大数字 → 省份出生率（520px）
互动　　　「你在哪一届」滑块
启示　　　三条必须开始算的账
```

**为什么不再左右并排：** 双列时每张图只有 540px 宽，图表里的标签、图例、坐标轴全部要压缩。改成单列后每张图获得整幅宽度，同时页面被拉长一倍——读者的滚动速度慢下来，一张图的停留时间从两秒变成十秒。

**四个年代为什么用教室：** 「人口减少」是一个抽象判断，教室是一个具体空间。同一间教室，1996 年坐 60 人，2025 年只坐 23 人——这个对比不需要解释。

## 三、三条数据线

| 变量 | 区间 | 变化 | 数据源 |
|---|---|---|---|
| 出生人口 | 1996–2025（30 年） | 2067 万 → 792 万，**−61.7%** | 国家统计局 |
| 结婚登记 | 2010–2025（16 年） | 峰值 1346.9 万对（2013）→ 610.6 万对（2024）→ 676.5 万对（2025） | 民政部 |
| 高校毕业生 | 2008–2026（19 年） | 559 万 → 1270 万，**+127%** | 教育部 |

**核心图（贰段第一张）：三条线的指数化对比。** 以各自起点为 100，把单位不同的三个指标放进同一坐标——出生线跌到 38，结婚线跌到 54，毕业线涨到 227。三条线从同一点出发，一条向上，两条向下，形成一把张开的剪刀。

**最刺眼的对照：** 2026 届毕业生 1270 万，2025 年出生人口 792 万，相差 478 万。2026 届对应 2004 年前后出生（当年 1593 万）；等 2025 年这批孩子 2043 年走进考场，高校的招生计划还停在 1270 万这个量级。

## 四、分析层次

报道不是罗列数字，而是做了三层推进：

1. **现象层**：三十年下降 61.7%，两次反弹都是假的。
2. **机制层**：出生人口 ≈ 育龄妇女数量 × 生育率。分母五年少 1600 万（不可逆），分子 1.01 远低于更替水平 2.1。所以「即使生育率明天回升，出生人口仍会下降」——这是算术，不是意愿。
3. **后果层**：按学段传导（幼儿园 3 年 / 小学 6 年 / 初中 12 年 / 高中 15 年 / 大学 18 年），并给出三个领域的量级推算（教师需求、养老结构、招生计划）。

## 五、视觉

- **字体：全篇仿宋**（FangSong / FangSong_GB2312 / STFangsong 栈）。正文 20px、字重 600。仿宋笔画细，必须靠字号和字重补回可读性。
- **无卡片**：没有白底、没有圆角、没有投影。内容直接排在宣纸色（`#F7F5F0`）上，只用 2px 实线（信息块顶部）和 1px 虚线（分隔）建立层级。
- **三色语义**：墨黑（主体）、朱红 `#9B2D1F`（下降 / 强调）、赭金 `#B8912F`（对照 / 互动）。
- **图片**：16 张，全部为 **Wikimedia Commons 的真实历史与现场影像**（CC BY-SA / CC BY / CC0 / 公有领域），无一张由 AI 生成。包括 1978 年北京幼儿园与上海两所托儿所、20 世纪 70 年代少先队入队、2020/2023/2024 年三所小学、2025 年上海黄浦婚姻登记中心、一场中式婚礼、清末母婴合影、宁波高中教室、宁波某大学毕业典礼、一名 2022 年高中毕业生的毕业照等。
- **叠卡组图**：三处（三条线 / 三个变量 / 缺口往上推）。三张照片叠成一叠「相纸」，只有最上面一张显示图像，后两张是米白纸张的边缘，靠投影分层；点击标签或照片，上图退回纸堆、下一张滑到最上并淡入。相比并排三图，它占一屏、只讲一件事，且能把「更多照片」这件事本身做成交互。

## 七、交互

这一版的改动重点：**从「翻页看」变成「动手查」**。每一张图都有一个可操作的入口，而不是被动展示。

| 位置 | 交互 | 反馈 |
|---|---|---|
| 三十年曲线 | 滚轮缩放、按住拖动、底部滑块 | 可聚焦任意年份区间 |
| 三十年曲线 | 点击折线上的圆点 | 下方弹出该年数值、同比变化、当年的政策背景 |
| 两次反弹柱图 | 点击任意柱形 | 弹出该年出生数、与上年的差值、当年发生了什么 |
| 三条线剪刀差 | 点击图例 | 隐藏/显示任意一条线，对比两条线的相对走势 |
| 三条线剪刀差 | 滚轮缩放 | 聚焦到某一段 |
| 结婚登记 | 点击柱形 | 弹出该年结婚对数 + **次年出生人口**，直接看两者关系 |
| 省份出生率 | 点击任一省份条形 | 弹出该省与全国平均的差（千分点） |
| 叠卡组图 ×3 | 点击标签 / 点击照片 / 键盘 ←→ | 切换照片、图注与编号同步更新 |
| 你在哪一届 | 拖动滑块 | 实时显示该届人数、与 2025 年的差值和百分比 |

**背景音乐**（右下角按钮，四条声波跳动）：

用 Web Audio 实时合成，**音乐盒音色**：

- C 大调四个和弦循环（C → Am → F → G），每和弦四拍，琶音上行
- 每个音符由基频 + 二层泛音叠成，快起慢落，模拟音乐盒的金属质感
- 两个低频正弦做铺底，缓慢起伏
- 速度 660ms 一拍，比常规背景音慢一档，不抢注意力
- 主音量 0.72

**AI 朗读已删除。** 浏览器自带的 `speechSynthesis` 中文音色偏机械，与这篇报道的气质不合；而且朗读与音乐不能共存。声音最终只保留音乐这一种。

## 八、技术

- 单文件 HTML，**5.3 MB**，含 16 张 base64 图片 + ECharts 5.5.0 整包
- **零外部请求**，断网双击即可打开
- 5 张图表按墨色系重配，未用默认主题
- 叠卡组图为纯 CSS `transform` + 绝对定位分层，切换时不重排、不触发重绘

**改内容的流程：** 改 `_src.html`（图片走相对路径、CDN 引库），然后跑 `python build.py` 生成 `index.html`。

## 十、局限

1. 结婚登记 2021 年数据在本次检索中未取得，折线跨过该年。
2. 毕业生规模 2008 年起采用教育部统一口径，与 2007 年之前的统计口径存在差异，故未向前延伸。
3. 育龄妇女规模为普查推算值，只能标注「约」。
4. 教师需求、18 年后高考人数为量级示意，不构成预测。
5. 配图来自 Wikimedia Commons（CC 授权 / 公有领域），为真实历史与现场影像，仅作时代与场景示意，人物与本文数据无对应关系。
